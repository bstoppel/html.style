# html.style

A modern web standards-based HTML and CSS framework, template starter, design system, and methodology.

## Features

- **CSS Framework** - Pre-built components and utilities
- **HTML Templates** - Best practices starter templates
- **Design System** - Comprehensive styles, components, and guidelines
- **CSS Methodology** - Modern approach to writing maintainable CSS
- **Web Standards First** - Built on modern web platform features

## Installation

```bash
# NPM
npm install html.style

# Yarn
yarn add html.style
```

## Quick Start

```bash
# Using CLI (coming soon)
npx create-html-style my-project
cd my-project
npm install
npm start
```

## Directory Structure

- `/src` - Source files for development
- `/dist` - Distribution files (ready to use)
- `/docs` - Documentation
- `/website` - Project website source
