Getting Started

Get up and running with html.style in minutes

Installation

Choose your preferred installation method:

Option 1: Download (Recommended)

Download the latest release and extract it to your project:

# Download from GitHub Releases
https://github.com/bstoppel/html.style/releases

# Extract and copy dist/ folder to your project

Option 2: npm

npm install html.style

Option 3: Clone Repository

git clone https://github.com/bstoppel/html.style.git
cd html.style
# Use the dist/ folder in your project

Quick Start

Create a new HTML file with this minimal setup:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="color-scheme" content="light dark">
  <link rel="stylesheet" href="css/html.style.css">
  <title>My Project</title>
</head>
<body>
  <main>
    <h1>Hello html.style!</h1>
    <p>Start building with semantic HTML.</p>
    <button>Click Me</button>
  </main>
  <script type="module" src="js/html.style.js"></script>
</body>
</html>

That's it! Open your HTML file in a browser and you're ready to build.

File Structure

After installation, your project should include:

your-project/
├── css/
│   └── html.style.css      # Framework stylesheet
├── js/
│   └── html.style.js       # Optional enhancements
├── favicon.svg             # Dark mode favicon
├── site.webmanifest        # PWA manifest
└── index.html              # Your HTML file

Basic Usage

Semantic HTML

html.style styles semantic HTML directly. No classes needed for basic elements:

<!-- Buttons -->
<button>Primary Button</button>
<button class="button--secondary">Secondary</button>

<!-- Forms -->
<form>
  <label for="email">Email</label>
  <input type="email" id="email">
  <button type="submit">Submit</button>
</form>

<!-- Typography -->
<h1>Heading 1</h1>
<p>Paragraph text with <strong>bold</strong> and <em>italic</em>.</p>

Layout Primitives

Use layout primitives for responsive layouts without media queries:

<!-- Stack: Vertical layout with consistent spacing -->
<div class="stack">
  <h2>Section Title</h2>
  <p>Content here</p>
  <button>Action</button>
</div>

<!-- Cluster: Horizontal wrapping layout -->
<div class="cluster">
  <button>One</button>
  <button>Two</button>
  <button>Three</button>
</div>

<!-- Grid: Auto-responsive grid -->
<div class="card-grid">
  <article class="card">Card 1</article>
  <article class="card">Card 2</article>
  <article class="card">Card 3</article>
</div>

<!-- Center: Max-width container -->
<div class="center">
  <p>Centered content with max-width</p>
</div>

Components

Use component classes for cards, alerts, and other UI elements:

<!-- Cards -->
<article class="card">
  <h3>Card Title</h3>
  <p>Card content adapts to container size.</p>
</article>

<!-- Alerts -->
<div class="alert alert--success" role="alert">
  <strong>Success!</strong> Operation completed.
</div>

<div class="alert alert--warning" role="alert">
  <strong>Warning!</strong> Please review.
</div>

Theming

Automatic Dark Mode

Dark mode works automatically based on system preferences. Add this to enable:

<meta name="color-scheme" content="light dark">

Manual Theme Toggle

Let users manually switch themes with JavaScript:

<!-- Theme toggle button -->
<button onclick="ThemeManager.toggle()">Toggle Theme</button>

<!-- Include the JS -->
<script type="module" src="js/html.style.js"></script>

Customizing Colors

Override design tokens in your own CSS:

/* Custom brand color */
:root {
  --p-brand-hue: 200;  /* Blue instead of purple */
}

/* Custom semantic colors */
:root {
  --color-action-primary: oklch(0.5 0.2 200);
}
