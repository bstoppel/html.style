Built for the Future

html.style uses cutting-edge web standards that work today in modern browsers.

OKLCH Colors

Perceptually uniform color space with Display P3 wide gamut support. Better accessibility and consistency.

oklch(0.6 0.18 260)

Container Queries

Components adapt to their container, not the viewport. True component portability and reusability.

@container (inline-size > 400px)

Semantic HTML

Atoms layer styles HTML tags directly. No class soup. Maximum accessibility and SEO out of the box.

<button>Just Works</button>

Cascade Layers

Predictable specificity with @layer. Organized architecture following Atomic Design methodology.

@layer reset, tokens, atoms...

Native Theming

Browser-native dark mode using light-dark() function. Single stylesheet, automatic theming.

light-dark(#fff, #000)

Get Started in Seconds

1. Download

Get the latest release from GitHub or install via npm. 

npm install html.style

2. Include

Link the stylesheet in your HTML. That's it. 

<link rel="stylesheet"
  href="css/html.style.css">

3. Build

Write semantic HTML and start building. No configuration, no build process, no complexity.
